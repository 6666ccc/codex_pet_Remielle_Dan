# Codex 蕾米埃尔宠物

基于官方 GIF 图源制作的 Codex v2 自定义宠物「蕾米埃尔」。角色形象保留粉发、星形发饰、小翅膀与设备道具。

## 状态映射

- 普通状态（idle）：`待机中.gif`
- 需要输入（waiting）：`待机.gif`
- 运行中（running）：`修改文件.gif`
- 就绪（review）：`完成.gif`
- 阻塞（failed）：独立制作的 8 帧失败/阻塞动画

## 动画流畅度说明

Codex v2 自定义宠物图集规定每个标准动作只能使用固定的 8 帧。由于原始 GIF 通常包含更多帧，制作图集时必须从原动画中选取并压缩为 8 个代表帧，因此成品动画的流畅度会低于原始 GIF。这是 Codex 宠物图集格式的帧数限制，并非原始素材损坏或播放异常。

## 已知问题

在 Codex 桌面端 `26.721.4979.0` 中，任务开始运行后，浮动宠物窗口可能仍显示普通待机动作；将鼠标移入宠物后再移出，才会刷新为正确的运行中动作。

这是 Codex 桌面端 `avatarOverlay` 的任务状态订阅/重新渲染问题，并非本宠物包的状态映射或精灵图错误。自定义宠物包只包含静态元数据与图集，无法主动监听任务状态，因此目前不能在本项目内彻底修复。

临时解决方法：

- 将鼠标移入宠物后再移出。
- 收起宠物，然后重新唤出。
- 等待 Codex 桌面端后续版本修复浮窗状态刷新。

## 内容

- `codex-pet/`：可直接安装的 Codex 宠物包，含 `pet.json` 与 `spritesheet.webp`。
- `pet-build/`：完整构建过程文件、动作行、提示词、质量检查结果与最终精灵图。
- `source-images/`：六张原始 GIF 图源及参考拼图。
- `codex-pet.html`：本地预览页面。

## 安装

将 `codex-pet/` 中的文件复制到：

```text
%USERPROFILE%\\.codex\\pets\\
```

然后重启 Codex。该宠物使用 v2 图集格式（8 列 × 11 行，1536 × 2288）。

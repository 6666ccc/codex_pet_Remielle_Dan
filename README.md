# Codex 蕾米埃尔宠物

基于官方公开发布的 GIF 素材制作的 Codex v2 自定义宠物「蕾米埃尔」。

角色保留了粉色头发、星形发饰、小翅膀和设备道具等主要外观特征，并针对 Codex 的不同任务状态制作了相应动画。

## 预览与状态映射

| Codex 状态 | 动画用途 | 素材来源 |
| --- | --- | --- |
| `idle` | 普通待机 | `待机中.gif` |
| `waiting` | 等待用户输入 | `待机.gif` |
| `running` | 正在运行任务 | `修改文件.gif` |
| `review` | 任务完成，等待检查 | `完成.gif` |
| `failed` | 任务失败或受阻 | 独立制作的 8 帧失败／阻塞动画 |

## 项目内容

- `codex-pet/`：可直接安装的 Codex 宠物包，包含 `pet.json` 和 `spritesheet.webp`。
- `pet-build/`：完整的构建过程文件，包括动作行、提示词、质量检查结果和最终精灵图。
- `source-images/`：制作过程中使用的六张原始 GIF 素材及参考拼图。
- `codex-pet.html`：用于查看动画效果的本地预览页面。

## 安装方法

### 方法一：手动安装

将 `codex-pet/` 目录中的文件复制到：

```text
%USERPROFILE%\.codex\pets\
```

复制完成后，请完全退出并重新启动 Codex。

本宠物使用 Codex v2 图集格式：

- 图集尺寸：1536 × 2288 像素
- 图集布局：8 列 × 11 行
- 每个标准动作：8 帧

### 方法二：让 Codex 协助安装

复制下面的内容并发送给 Codex：

> 请阅读并下载 [codex_pet_Remielle_Dan](https://github.com/6666ccc/codex_pet_Remielle_Dan) 项目，检查其中的宠物包文件，并将其安装到当前设备的 Codex 宠物系统中。安装完成后，请确认 `pet.json` 和 `spritesheet.webp` 已放置在正确目录，并告诉我是否需要重新启动 Codex。

## 关于动画流畅度

Codex v2 自定义宠物图集规定，每个标准动作只能使用固定的 8 帧。

由于原始 GIF 通常包含更多帧，制作图集时需要从原动画中选取具有代表性的画面，并将其压缩为 8 帧。因此，成品动画的流畅度可能低于原始 GIF。

这是 Codex 宠物图集格式的帧数限制，并非原始素材损坏或动画播放异常。

## 已知问题

在 Codex 桌面端 `26.721.4979.0` 中，任务开始运行后，浮动宠物窗口有时仍会继续显示普通待机动作。将鼠标移入宠物区域后再移出，窗口才会刷新为正确的运行中动作。

该现象可能与 Codex 桌面端 `avatarOverlay` 的任务状态订阅或重新渲染有关，并非本宠物包的状态映射或精灵图错误。

自定义宠物包仅包含静态元数据和图集，无法主动监听 Codex 的任务状态，因此暂时无法在本项目内彻底解决该问题。

临时解决方法：

- 将鼠标移入宠物区域后再移出。
- 收起宠物，然后重新唤出。
- 完全退出并重新启动 Codex。
- 等待 Codex 桌面端后续版本改进浮动窗口的状态刷新机制。

# 蕾米埃尔注视机制

## 锚点与动作预算

- 双腿、坐姿下半身和画面基线保持固定，白色设备始终被双手抱住并与身体连接。
- 眼睛首先引导方向：原有粉黄螺旋虹膜、瞳孔和高光作为完整眼球表面一起移动，不能添加新眼白、悬浮瞳孔或第二层眼睛。
- 眼睑、眉毛、头部和颈部随后做克制的小幅跟随；上身只做轻微转向，翅膀和发梢延迟少量跟随。
- 白色设备是刚性道具，位置大体稳定，只随手臂和上身轻微转动；转向时允许头发、脸颊和设备产生自然遮挡关系。
- 每 22.5° 的变化量保持均匀。禁止旋转、倾斜或扭曲整张角色图来伪造注视方向。

## 四个基准姿态

- `000 / 上`：螺旋虹膜与瞳孔明显位于眼眶上部，眼睑和眉毛抬起，头部轻微仰起；下半身与设备不动。
- `090 / 屏幕右`：双眼、鼻尖和面部朝屏幕右侧越过头部中心，左侧脸颊更可见；星形发饰仍保持角色固有侧别，设备仅小幅随上身转动。
- `180 / 下`：螺旋虹膜与瞳孔明显位于眼眶下部，眼睑压低，头部向设备方向低下；设备对下半张脸的遮挡略增。
- `270 / 屏幕左`：双眼、鼻尖和面部朝屏幕左侧越过头部中心，右侧脸颊更可见；星形发饰可被发丝部分遮挡，但不得翻到另一侧。

## 连续性要求

- `000 → 090 → 180 → 270 → 000` 必须构成连续顺时针注视环。
- 对角方向同时保留对应的水平与垂直线索，不得回到正面或跳到错误象限。
- 头型、脸型、刘海、星形发饰、翅膀、服装、设备、线宽和配色在全部方向中保持同一角色身份。

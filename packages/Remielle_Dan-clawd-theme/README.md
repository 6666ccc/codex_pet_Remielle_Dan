# 蕾米埃尔 · Clawd（Remielle_Dan）

Clawd on Desk 自定义主题，版本 `0.5.2`。

## 安装

将整个 `Remielle_Dan-clawd-theme` 目录复制到：

```text
%APPDATA%\clawd-on-desk\themes\Remielle_Dan-clawd-theme\
```

然后在 Clawd on Desk 的「设置 → Theme」中选择「蕾米埃尔 · Clawd」。
